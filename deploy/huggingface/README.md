# ☁️ AZ-900 Tutor · demonstração

Assistente de estudo com IA para a certificação **Microsoft Azure Fundamentals (AZ-900)**.
Responde dúvidas com base na documentação oficial da Microsoft (sempre com as fontes), aplica simulados e mostra o desempenho por área.

**Sobre esta demonstração**

- Roda num servidor **gratuito, só com CPU**: cada resposta pode levar até 1 minuto. O simulado é instantâneo.
- A IA (Qwen 2.5, 3B) roda **dentro do próprio servidor**, sem nenhuma API paga.
- Seu histórico fica só no seu navegador e pode ser apagado quando o servidor reiniciar.
- Se o servidor estiver "dormindo" (sem uso há um tempo), ele leva alguns minutos para acordar.

Código, documentação e resultados da avaliação: **https://github.com/julia241005/az900-tutor**

Projeto pessoal de estudo, sem vínculo com a Microsoft.
